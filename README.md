# PCpower
Alexa and local web interface for powering on and off a PC using a Raspberry pi Pico W

Connects to Power, Reset and LED Pins on motherboard via optocupplers
Connects to always on USB on the PC to supply power and Gives key commands for shortcut keys via a emulated HID keyboard using F13.

Pins in use:<br>
8 - PC Power + via optocuple<br>
12 - PC Reset + via optocuple<br>
4 - Power LED + via optocuple<br>

Untested at this stage.
